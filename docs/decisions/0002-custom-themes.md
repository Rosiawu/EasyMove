# 自定义主题决策记录

## 背景

- 需求：用户可以选择自己的图片作为 EasyMove 背景主题。
- 验收：图片能导入、立即应用、切回内置主题，并在重启后继续保留。

## 决策

- 支持 PNG、JPEG 和 WebP，单张最大 50 MB，并使用 Electron `nativeImage` 验证可解码性。
- 导入时复制到应用用户数据目录，不依赖原图后续位置，也不上传网络。
- 渲染进程通过受限的 `easymove-theme://custom/background` 协议读取图片，不获得任意文件路径访问权。
- 当前主题名称保存在 `localStorage`，自定义图片元数据和文件由主进程管理。
- 三套内置主题始终保留；“我的”未启用时点击会恢复保存的图片，已启用时点击会更换图片。

## 风险与缓解

- 超大或无效图片：导入前限制 50 MB 并验证解码。
- 原图删除导致主题失效：导入时保存独立副本。
- 任意本地文件泄露：协议只允许固定的 `custom/background` 资源。
- 缓存显示旧图：主题 URL 附带文件修改时间作为版本参数。

## 回滚

- 回滚自定义主题提交即可恢复仅内置主题；用户数据目录中的图片可保留，不影响应用运行。
